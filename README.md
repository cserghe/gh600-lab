# gh600-lab

Hands-on lab repo for the GitHub Copilot GH-600 exam (18 Oct 2026).

Every file in this repo comes from the "GH-600 Lab Workbook - Annotated Examples".
The lab files live on the `labs` branch. Start with `LABS_EXPLAINED.md` there.

- Tiny TypeScript app: `src/cart.ts` has a deliberate rounding bug; `npm test` shows one failing test.
- Copilot config: `.github/` (instructions, custom agents, hooks, workflows).
- Evaluation: `eval/`. Helper scripts: `scripts/`.
